# 使用说明

适用版本：0.3.1 累计功能更新。最终安装包与设备验证范围见[兼容性报告](./兼容性报告.md)。

小牛霸王学习机使用随包本地 FCEUmm WASM 核心，模拟器在浏览器中运行，飞牛原生安装无需 Docker。核心与七款内置 ROM 不依赖 CDN，应用不提供商业 ROM 下载站入口。界面、菜单、设置和提示均为简体中文；卡带详情中的中文标题和说明便于查找与操作，游戏自身的画面语言以“卡带语言”一栏为准。七款内置游戏保持原版，未修改为中文 ROM。新增烟花守卫与记忆翻牌，原五款不变；来源、署名和 GPL 对应源码见[内置游戏授权](./内置游戏授权.md)。本应用并非任天堂或小霸王官方产品，也未获得其官方授权。

## 打开卡带

在“全部卡带”中选择游戏，查看详情里的操作说明，再点击“启动卡带”。进入播放器后，点击画面中的开始按钮。浏览器需要这次点击才能启用声音。

播放器底部可以暂停、继续、重置、静音和调节音量；画面和控制区按当前可见视口分配空间。“全屏游玩”优先请求整台学习机的系统全屏，不允许时回退页内大屏，不只放大画布。切换到其他窗口或隐藏页面后，运行会自动暂停并释放输入；回来后点击继续。

“我的收藏”显示自己收藏的卡带，“最近游玩”便于返回最近启动的卡带。导入的卡带可以在详情页重命名或删除；删除会同时移除该卡带关联的服务器存档和游玩记录，操作前先下载完整备份。内置卡带由安装包管理，不能在这里重命名或删除。

## 查找卡带与翻页

卡带库默认每页显示 20 条。列表顶部和底部提供翻页栏，可到首页、上一页、下一页、末页；输入页码后按 Enter 跳转。每页数量可选 20、50、100，也可输入 1–500 的自定义数量。显示的起止条目、结果总数和页数以当前筛选结果为准；没有匹配卡带时显示空结果，不显示不存在的条目区间。

搜索在停止输入约 250 毫秒后查询完整卡带库，不是只搜索当前页；名称、原名和标签都可用于查找。中文及其他 Unicode 文本按字符匹配，`%`、`_` 作为普通搜索字符，不是通配符。分类、收藏、最近游玩和排序也作用于全库；侧栏统计不等于当前页数量。

修改搜索、分类、视图、排序或每页数量会回到第 1 页。收藏变化、导入或删除后会重新读取结果和全库统计；若尾页已经不存在，自动回到有效页，不必手动清空筛选。分页偏好只尝试保留在当前标签页的会话存储中，不写入服务器的“使用设置”，也不修改备份中的设置。

### 显示全部与大库

“全部”是需要主动选择的展示方式，不是默认加载整个卡带库。应用按每批最多 500 条依次读取当前筛选结果，显示加载进度，并允许取消；取消只停止继续加载，不会删除已存于服务器的卡带。搜索或筛选变化后不沿用旧结果。

全部展示采用虚拟列表，只绘制可见区域附近的有限卡片，滚动时继续显示后续内容；DOM 中的卡片数量不代表实际卡带总数。卡带很多时优先使用分页，降低一次读取和浏览器内存占用。实际设备性能和分页界面的验证范围见[兼容性报告](./兼容性报告.md)。

## 导入自己的卡带

1. 准备自己拥有使用权的 `.nes` 文件，例如有明确授权的自制游戏或依法取得使用权的个人卡带文件。
2. 点击“导入卡带”，选择文件或将文件拖入导入区域。
3. 单个文件可填写显示名称；留空时使用文件名。
4. 点击“导入”，等待逐项结果。失败项可查看原因后重试。

当前服务端接受 iNES 或 NES 2.0 格式的 `.nes` 文件，单个文件上限为 8 MiB。扩展名正确仍需通过文件头和长度校验。`.fds`、`.unf`、`.unif` 和压缩包当前不作为可用导入格式；把其他格式改名为 `.nes` 不能转换文件。

导入成功表示文件已入库，能否运行还取决于卡带所需的存储映射器和外设。七款内置游戏有真实 WASM 短程运行与状态恢复证据；新增烟花守卫、记忆翻牌分别执行 638、590 帧并验证手柄动作与音频采样，不等于通关、扬声器听音或实体设备测试；其他卡带需要逐一验证。

## 从服务器目录导入

1. 从飞牛桌面或客户端打开本应用，打开“服务器目录”。
2. 点击“添加卡带目录”，在飞牛目录窗口中选择卡带文件夹，再确认“选择并授权”。无需先离开应用去系统设置。
3. 授权完成后自动返回并刷新目录；如未出现新目录，点击“刷新授权目录”。只有一个可用目录时可直接进入，多个目录时选择需要的目录。
4. 勾选 `.nes` 文件并点击“导入已选 N 项”，或点击“扫描此目录”批量检查当前目录及子目录。
5. 查看已检查、找到、已导入和失败数量，关闭窗口后在卡带库查看结果。

浏览器阻止授权弹窗时，可点击“在当前窗口选择并授权”，完成后返回应用。客户端未提供可用原生目录选择时，按提示“在浏览器中打开本应用”，登录后再添加目录；必要时使用客户端的“在浏览器打开”菜单。取消、超时或会话变化后重新发起授权，不重复使用旧授权回调。

目录权限来自飞牛真实登录身份和目录授权。应用只显示目录/文件名称，选择器返回的物理路径不作为应用访问凭据；浏览、导入和扫描均继续由服务端检查授权和 ACL。个人卡带、存档、收藏及设置按当前用户隔离，添加目录不会把私有文件开放给其他用户。本地预览不提供 NAS 目录能力，遇到“服务器目录暂不可用”可先上传 `.nes` 文件。真实飞牛浏览器及客户端整条授权流程仍待实机验证。

### 大目录、取消与权限变化

- 浏览窗口只显示有限条目；提示目录较大时，使用“扫描此目录”，不要把当前列表当作完整目录。
- 扫描按游标分批检查，每批最多 128 个名称，单次全局最多检查 16,384 个条目，目录深度不超过 32，任务时间上限为 10 分钟。非卡带条目也计入检查上限；达到限制会说明未检查全部文件。
- 点击“取消扫描”只停止后续检查，已经导入成功的卡带继续保留。扫描失败或批量导入中断也可能已经完成部分导入，卡带库会刷新；查看结果后可再次“扫描此目录”，已有内容按规则去重。
- 授权撤销、句柄失效或收到需要刷新提示时，旧目录和勾选项会清除。点击“刷新授权目录”，必要时重新“添加卡带目录”，再重新选择文件；不能继续使用旧选择。

## 键盘与双人操作

默认键位如下；游戏中的 A、B 指模拟手柄上的按钮。

| 功能 | 玩家一 | 玩家二 |
| --- | --- | --- |
| 上、下、左、右 | 方向键 | W、S、A、D |
| A | X | H |
| B | Z | G |
| 开始 | Enter | U |
| 选择 | 右 Shift | T |

先点击播放器中央的运行按钮开启画面与声音，再按卡带的“开始”或“确认”键进入游戏；两者不是同一个操作。开始或继续后焦点交给游戏画面，键盘可以直接控制；点击工具栏或其他界面后，再点击画面返回游戏操作。游戏输入仅在游戏焦点内响应，文本框、菜单、工具栏和弹窗不会同时控制卡带；暂停、失焦、页面隐藏、切换设备或全屏状态变化会释放输入，恢复后需重新按下，不沿用按住键的重复事件。屏幕按钮的多指按住与取消分别处理，不能用合成事件测试代替真人多点触控验收。画面旁显示当前真实键位，点击“1P 键盘／2P 键盘”可切换查看双人映射，自定义后以此处显示为准。

点击播放器工具栏的“按键设置”可直接进入改键页，也可在“使用设置 → 按键与触屏 → 实体键盘映射”中点击要修改的键，再按下新按键，最后保存设置。两位玩家的按键不能重复。Esc 取消本次设置；浏览器快捷键和部分系统按键不能用于自定义。打开设置前暂停游戏，关闭后点击继续，不会自动续玩。

乒乓球是双人游戏，两位玩家需要分别控制自己的球拍。默认情况下，玩家一用上、下和 X，玩家二用 W、S 和 H；也可使用两个标准手柄。进入游戏、暂停和发球的具体步骤以卡带详情为准。

烟花守卫单人用方向键移动准星，Z 从左井、X 从右井发射，Enter 暂停；双人合作各控一座发射井。画面含闪烁效果，光敏感玩家请留意原作警示。记忆翻牌用方向键选卡、X 翻牌，Z 随机移动光标；双人轮流可共用一只手柄，交接时同时按 A+B（玩家一默认 X+Z）。两款仍是英文原版。

## 屏幕手柄与实体手柄

播放器工具栏可直接显示／隐藏屏幕手柄；在“使用设置 → 按键与触屏”可保存默认显示状态、大小、不透明度和位置。方向键与动作键可以同时按住，实体键盘与屏幕手柄也可交替使用。

“全屏游玩”会把游戏、工具栏、当前键位与屏幕手柄一起进入全屏。平台不允许系统全屏时改用页内大屏；点击退出按钮返回，页内大屏也可按 Esc 退出。控制区预留空间，不覆盖游戏画面；手机横屏把方向键和 A/B 放在画面两侧。打开“怎么玩”可查看这张卡带的说明和双人键位，游戏暂停后再阅读。较窄或矮的窗口通过“存档与输入设备”展开辅助面板，不影响主要游玩区域。

实体手柄使用浏览器的标准手柄接口。连接后按任意键唤醒，前两个标准手柄依次分配给玩家一和玩家二；十字键或左摇杆控制方向，下方/左侧面键对应 A，右侧/上方面键对应 B，开始和选择使用对应功能键。

手机多点触控、实体 USB/蓝牙手柄和飞牛手机端仍待实机验证。浏览器未识别为标准布局的手柄暂不能直接使用，也没有提供通用手柄改键功能。

## 学习键盘

在播放器右侧“输入设备 → 学习键盘设备”选择卡带需要的设备：

- “任天堂家庭电脑键盘（Family）”适用于使用 Family 键盘协议的程序。
- “小霸王学习键盘（Subor）”适用于使用 Subor 键盘协议的程序。
- 普通游戏选择“游戏手柄模式”。

启用学习键盘后，实体键盘按实际键位向卡带输入，也可展开屏幕学习键盘。需要输入字母、数字或标点时，先点击运行画面；在文本框、菜单或弹窗中操作时，输入留给界面。浏览器或系统保留的组合键可能优先响应，遇到这类按键可使用屏幕学习键盘。切回手柄模式后恢复游戏映射。

Family、Subor 两种键盘的按下、松开、组合键及切换已通过诊断测试。原装学习卡的启动、文字输入、BASIC 和教学功能仍待取得有合法使用权的卡带后逐项验证；当前没有随包提供商业学习卡。

## 保存与读取进度

播放器提供两种存档，它们的用途不同。

| 类型 | 保存内容 | 用法 |
| --- | --- | --- |
| 即时存档 | 当前模拟器状态与画面缩略图 | 选择槽位 1–10（槽位 10 可用于离开自动存档），点击“保存进度”或按 F5；读取后点击继续或按 F8 快捷读档 |
| 卡带电池存档（SRAM） | 卡带自身支持的持久化数据 | 运行时每 30 秒保存发生变化的数据，也可点击“保存卡带电池存档” |

即时存档依赖原卡带内容和核心版本，换 ROM 或更新核心后可能无法读取。电池存档只适用于本身提供这项能力的卡带，出现“没有可保存的电池存档”并不表示保存失败。结束游玩前手动保存，看到成功提示后再离开。

卡带、存档、收藏和设置保存在当前用户的服务器空间中。待上传快照会尝试保留在当前标签页的浏览器会话存储中；存储不可用或容量不足时仍保留在页面内存，并提示立即下载。它不是服务器存档，也不能替代完整备份；关闭标签页、清除浏览器数据或存储失败后仍可能丢失。

### 上传失败或发生冲突

网络失败时，播放器会显示待上传快照，可点击“下载本地快照”或“重试上传”。多个页面、设备同时修改同一槽位时，服务器按版本条件拒绝过期写入并提示冲突；尚有待处理快照时，不继续生成新的服务器存档覆盖它。保存、读取、重试和自动保存按顺序执行，等待当前操作完成。

1. 先点击“下载本地快照”，将待上传进度交给浏览器下载，并核对下载文件。
2. 进入“处理服务器冲突”后，如需保留双方进度，点击“保留两份，下载本地”。应用实际发起本地快照下载，服务器原存档不变；这里不是在服务器自动新增第四个槽位。
3. 如确定采用当前本地进度，点击“用本地进度更新服务器”。应用重新读取服务器版本后按条件上传；再次并发修改仍可能被拒绝。

正常状态下也可点击“下载当前即时存档”，不必先制造上传失败。下载的 `.state` 或 `.sav` 是单份快照，当前没有将这类裸文件直接导回的通用入口；迁移和恢复请使用完整 ZIP 备份。

### 离开播放器

返回卡带详情、切换页面或使用应用内导航时，播放器会先暂停并尝试保存变化的电池存档及待上传快照。未保存成功时显示“离开前保留进度”：

- “留在播放器”：取消离开，继续处理进度。
- “保存 / 重试后离开”：上传成功后再离开；冲突时先处理服务器冲突。
- “下载快照并离开”：实际发起本地下载，保留服务器原存档，请检查浏览器下载是否完成。
- “丢弃并离开…”：还需再次点击“确认丢弃并离开”；待上传本地进度会删除，服务器已有存档不变。

直接刷新、关闭页面或浏览器退出时，应用只能尝试同步保留快照并请求浏览器离开提示，不能保证异步上传或提示一定完成。重要进度先手动“保存进度”，确认成功，必要时再下载备份。

## 备份与恢复

打开“使用设置 → 备份与恢复”，点击“下载备份”。ZIP 包包含个人导入卡带、存档、设置以及收藏和最近游玩资料；内置卡带记录来源与校验值，恢复时匹配当前安装包中的对应游戏。

恢复时选择本应用导出的 ZIP，点击“恢复此备份”，再查看结果。恢复按增量合并处理，不会清空当前卡带库：

- 个人导入卡带按内容校验值去重；已经存在时沿用当前显示名称。
- 内置卡带与个人导入卡带分别匹配，即使文件内容相同，也各自保留名称和存档。
- 同一张卡带已有的存档槽位保留，冲突会列出；不同来源卡带的同号槽位分别保存。
- 已有设置值优先，收藏合并。

恢复或保存设置正在进行时，其他会修改设置/资料的操作会暂时锁定，避免重复提交；请等待完成提示后再操作。更新、卸载、换机前先下载备份，并保留原 ZIP。恢复后检查卡带数量、显示名称和每个存档槽位，再开始使用。

## 画面、声音与常见情况

- 没有声音：先点击开始或继续，检查播放器静音、音量及系统输出设备；部分游戏在标题画面或某些阶段没有音效。
- 按键无反应：点击运行画面，确认没有处于暂停、弹窗或文本编辑状态，再检查是否选择了正确的输入设备。
- 切回页面后停住：点击继续，自动暂停会保留当时运行状态。
- “核心不可用”：应用未找到完整的本地模拟器资源，重新打开仍失败时应检查安装包完整性。
- 无法读取即时存档：确认是同一份 ROM 和兼容的核心版本，先保留备份与本地快照。

## 关于与自愿支持

“关于与支持”显示实际运行服务返回的版本；0.3.0 对应包应显示 0.3.0，无法读取时不伪造版本。可下载对应源码和查看开源许可。正常版显示微信、支付宝两张已经确认使用授权的原始赞赏码，图片完整放在白底区域；可查看大图或下载原图，支持与否不影响任何功能。仅显式不含赞赏码的构建会显示“赞赏码尚未配置”。

图片或网络加载失败时会提示错误，可关闭后重新打开；这不表示卡带或核心不可用。最终安装包中的源码、许可和赞赏码下载是否完成核验，以匹配交付的外部报告为准。
