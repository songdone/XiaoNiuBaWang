# 安装、更新与卸载

适用版本：0.3.1。应用为飞牛原生 FPK，使用专用应用用户及 Unix 套接字，无需 Docker。

## 选择安装包

| 文件 | 用途 |
| --- | --- |
| 小牛霸王学习机-ARM64.fpk | ARM64 NAS |
| 小牛霸王学习机-x86_64.fpk | Intel/AMD x86_64 NAS |
| 小牛霸王学习机-源码.zip | 与安装包匹配的完整对应源码 |
| 开源许可.txt | 应用、核心、游戏及依赖许可说明 |
| SHA256SUMS | 交付文件校验值 |

确认 NAS 架构、系统版本、包版本及校验值后安装。manifest 声明最低飞牛版本 `1.2.0401`，最低版本和完整设备范围见[兼容性报告](./兼容性报告.md)。

开发者和发布者名称均为 `6uos`，两处链接均指向[GitHub 公开源码仓库](https://github.com/songdone/XiaoNiuBaWang)。安装旧版本的设备不会自动获得新版元数据。

实际 signed/unsigned 状态随包记录，不把未签名写成已签名。当前平台提交要求以实际渠道为准，不据此断言所有应用必须提供开发者证书；生成安装包不表示应用已获审核批准。

## 安装与首次使用

1. 使用应用中心的手动安装入口，选择符合设备架构的 FPK。安装前存在旧资料时先确认备份可读取。
2. 按提示安装并启动，从飞牛桌面打开应用；只看到任务提交不等于安装成功。
3. 确认七款内置卡带和“关于与支持”的实际服务版本。
4. 选择卡带并点击“启动卡带”，再点击画面运行按钮开启画面与声音。
5. 玩家一默认方向键移动，X=A、Z=B、Enter=开始、右 Shift=选择；玩家二 W/S/A/D、H=A、G=B、U=开始、T=选择。改键后以画面旁当前键位为准。
6. 工具栏可显示/隐藏屏幕手柄、查看玩法、改键或全屏游玩。系统全屏被拒绝时使用页内大屏，按退出按钮返回。
7. 上传有权使用的 `.nes`，或在“服务器目录 → 添加卡带目录”中选择并授权，然后浏览导入或扫描；取消保留已导入内容。

完整操作见[使用说明](./使用说明.md)。本地预览不提供 NAS 目录权限；无法访问文件时检查真实登录、用户授权和 ACL，不能通过扩大权限或绕过链接检查解决。

## 数据与备份

数据目录为 `${TRIM_PKGVAR}/xiaoniubawang-data`，包含 SQLite、用户卡带和存档，不能作为公开网页目录。

更新、卸载或迁移前：

1. 保存当前游戏，处理尚未上传的快照和冲突。
2. 在“使用设置 → 备份与恢复”下载完整 ZIP，保存到应用目录之外并先确认备份可读取。
3. 保留旧包、对应源码和校验值。
4. 使用平台允许的保数据更新流程，不卸载重装绕过同版本限制。
5. 更新后检查卡带总数、收藏、设置和各槽位，分别试读即时状态及电池存档。

恢复为增量合并：内置与个人来源分别匹配，已有槽位保留并列出冲突。重复操作须等待当前保存或恢复结束。会话快照和页面内存只是失败兜底，不是可靠备份；关闭或刷新不保证上传完成。

平台原生文件压缩与应用内导出的 ZIP 格式不同，不要把文件压缩包直接当作应用恢复格式。数据库降级和所有平台的卸载保留行为尚未验证，回退前必须保留当前资料。

## 卸载与重新安装

1. 先保存游戏并下载应用内完整备份，核对文件。
2. 阅读平台的数据删除提示后决定是否卸载；不依赖卸载自动保留数据。
3. 重新安装后使用应用内备份恢复，检查名称、进度和冲突列表。

应用脚本不主动删除资料，但系统保留行为仍取决于平台。通过服务器目录导入的原 ROM 不由本应用删除。彻底清理资料须在确认备份后由用户通过系统数据管理执行。

## 从源码重建

构建入口为 `scripts/build.sh`，版本读取 `branding/brand.json`。公开仓库不包含私有赞赏原图和本机工具链缓存；准备 Go 1.26、Node.js、官方 fnpack 及验包工具后，按[README](../README.md)中的完整命令构建。

三种模式互斥：

- `--publish`：官方 fnpack 1.2.3 普通打包流程，未签名状态如实记录，不代表平台批准。
- `--nosign`：本地测试流程。公开源码测试包使用 `--nosign --without-support --no-deliver`。
- `--release`：显式选择签名流程，验证预期公开证书、内容和签名，签名后不改包。

正常发行包必须含原始赞赏图片并通过校验；源码测试包显式禁用图片，不生成或替换二维码。包内源码下载入口为 `source/source.zip`，许可入口为 `licenses/INDEX.txt`。
