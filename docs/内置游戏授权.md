# 内置游戏授权

本版应用为 0.3.0 累计更新；以下固定游戏版本属于原作，不随应用版本替换。随包提供以下七款授权明确的 NES 自制游戏。在原有五款基础上仅增加烟花守卫与记忆翻牌，原五款 ROM、目录条目和来源记录保持不变。全部使用上游原始 ROM，未修改程序、文字或画面资源。没有随包提供商业游戏合集或商业学习卡。

应用界面及游戏标题、简介、操作说明为简体中文；ROM 自身的画面语言单独记录。双人乒乓球、虚空枪骑兵、仓库推箱依据源码标注 `en`；新增烟花守卫、记忆翻牌的固定源码与实际运行画面均有英文文字；网络大师、欢乐割草保守标注 `und`，表示画面语言仍待核验。七款均为 `romTranslated: false`，不能宣传为汉化 ROM。
